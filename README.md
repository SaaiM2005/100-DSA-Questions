















































































| Command   | Purpose                  | Common Parameters                                                                      |
| --------- | ------------------------ | -------------------------------------------------------------------------------------- |
| `ls`      | List files/directories   | `-l` (long listing), `-a` (show hidden files), `-h` (human readable), `-R` (recursive) |
| `pwd`     | Show current directory   | No major parameters                                                                    |
| `cd`      | Change directory         | `cd ..` (parent directory), `cd ~` (home directory)                                    |
| `mkdir`   | Create directory         | `-p` (create parent directories)                                                       |
| `rmdir`   | Remove empty directory   | `-p` (remove parent directories)                                                       |
| `rm`      | Remove files/directories | `-r` (recursive), `-f` (force), `-i` (interactive)                                     |
| `cp`      | Copy files/directories   | `-r` (recursive), `-v` (verbose)                                                       |
| `mv`      | Move/rename files        | `-i` (prompt before overwrite), `-v` (verbose)                                         |
| `touch`   | Create empty file        | No common parameters                                                                   |
| `cat`     | Display file content     | `-n` (line numbers)                                                                    |
| `more`    | View file page by page   | No common parameters                                                                   |
| `less`    | Advanced file viewer     | Better navigation than `more`                                                          |
| `head`    | Display first lines      | `-n` (number of lines)                                                                 |
| `tail`    | Display last lines       | `-n` (lines), `-f` (follow log file)                                                   |
| `grep`    | Search text              | `-i` (ignore case), `-n` (line number), `-r` (recursive)                               |
| `find`    | Search files             | `-name`, `-type`, `-size`                                                              |
| `chmod`   | Change permissions       | `+x`, `-R`                                                                             |
| `chown`   | Change ownership         | `-R` (recursive)                                                                       |
| `ps`      | Show running processes   | `-e`, `-f`, `aux`                                                                      |
| `top`     | Monitor processes        | No major parameters                                                                    |
| `kill`    | Terminate process        | `-9` (force kill)                                                                      |
| `df`      | Disk space usage         | `-h` (human readable)                                                                  |
| `du`      | Directory size           | `-h`, `-s`                                                                             |
| `free`    | Memory usage             | `-h`                                                                                   |
| `uname`   | System information       | `-a` (all details)                                                                     |
| `whoami`  | Current user             | No parameters                                                                          |
| `history` | Command history          | No common parameters                                                                   |
| `tar`     | Archive files            | `-c` (create), `-x` (extract), `-v` (verbose), `-f` (file)                             |
| `zip`     | Compress files           | `-r` (recursive)                                                                       |
| `wget`    | Download files           | `-O` (output file)                                                                     |
| `curl`    | Transfer data            | `-O`, `-X`, `-I`                                                                       |
| `ping`    | Check connectivity       | `-c` (count packets)                                                                   |
| `ssh`     | Remote login             | `-p` (port)                                                                            |
| `scp`     | Secure copy              | `-r` (recursive), `-P` (port)                                                          |
